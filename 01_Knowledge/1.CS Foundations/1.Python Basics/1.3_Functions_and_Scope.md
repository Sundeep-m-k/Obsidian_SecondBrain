# Python Functions and Scope

## What is it?

Functions are reusable blocks of code that take inputs (parameters) and return outputs. Scope determines which variables are visible where. Closures allow functions to "remember" variables from their creation context. Understanding these deeply is critical for writing correct, maintainable Python.

---

## Core Concepts

### 1. Function Definition and Call

```python
# Definition
def greet(name):
    """Function docstring"""
    return f"Hello, {name}"

# Call
result = greet("Alice")  # "Hello, Alice"
```

**Parameters vs Arguments:**
- Parameter: variable in function definition (`name` in `def greet(name):`)
- Argument: actual value passed in function call (`"Alice"` in `greet("Alice")`)

### 2. Default Parameters

```python
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}"

greet("Alice")  # "Hello, Alice"
greet("Bob", "Hi")  # "Hi, Bob"

# TRAP: Mutable defaults
def append_item(item, items=[]):  # ✗ BAD
    items.append(item)
    return items

# CORRECT:
def append_item(item, items=None):  # ✓ GOOD
    if items is None:
        items = []
    items.append(item)
    return items
```

### 3. *args and **kwargs

```python
# *args: Variable number of positional arguments (tuple)
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3, 4))  # 10

# **kwargs: Variable number of keyword arguments (dict)
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=30, city="NYC")

# Combined:
def func(a, b, *args, **kwargs):
    pass

# Call order: positional → *args → keyword → **kwargs
```

### 4. Scope: LEGB Rule

**Local → Enclosing → Global → Built-in**

```python
x = "global"

def outer():
    x = "enclosing"
    
    def inner():
        x = "local"
        print(x)  # Prints "local" (LEGB order)
    
    inner()
    print(x)  # Prints "enclosing"

print(x)  # Prints "global"

# Global keyword (modify global scope):
y = 0
def increment():
    global y
    y += 1

# Nonlocal keyword (modify enclosing scope):
def outer2():
    z = 0
    def inner2():
        nonlocal z
        z += 1
    inner2()
    print(z)  # 1
```

### 5. Return Values

```python
# Single return
def add(a, b):
    return a + b

# Multiple returns (as tuple)
def divmod(a, b):
    return a // b, a % b

quotient, remainder = divmod(17, 5)

# No explicit return → returns None
def nothing():
    pass

print(nothing())  # None
```

### 6. Closures

A closure is a function that "remembers" variables from its enclosing scope.

```python
def outer(x):
    def inner():
        return x  # Remembers x from outer scope
    return inner

add_5 = outer(5)
print(add_5())  # 5

# Each call creates new closure with different x:
add_10 = outer(10)
print(add_10())  # 10
```

**Closure Variables:**
```python
def multiplier(n):
    def multiply(x):
        return x * n
    return multiply

double = multiplier(2)
triple = multiplier(3)

print(double(5))  # 10
print(triple(5))  # 15

# Check closure variables:
print(double.__closure__)  # Contains n=2
print(triple.__closure__)  # Contains n=3
```

### 7. Decorators

Decorators are functions that modify other functions.

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("Before call")
        result = func(*args, **kwargs)
        print("After call")
        return result
    return wrapper

@my_decorator
def greet(name):
    return f"Hello, {name}"

greet("Alice")
# Output:
# Before call
# Hello, Alice
# After call

# Equivalent to:
# greet = my_decorator(greet)

# Decorator with arguments:
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def print_hello():
    print("Hello!")

print_hello()  # Prints "Hello!" 3 times
```

### 8. Lambda Functions

Anonymous functions for short, simple operations.

```python
# Regular function
def add(x, y):
    return x + y

# Lambda equivalent
add_lambda = lambda x, y: x + y

print(add(2, 3))        # 5
print(add_lambda(2, 3))  # 5

# Common uses:
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, numbers))  # [1, 4, 9, 16]

# Sort by second element:
pairs = [(1, 2), (3, 1), (2, 3)]
sorted_pairs = sorted(pairs, key=lambda p: p[1])  # [(3, 1), (1, 2), (2, 3)]

# Late binding trap:
functions = [lambda: i for i in range(3)]
print([f() for f in functions])  # [2, 2, 2] (NOT [0, 1, 2])

# Fix:
functions = [lambda i=i: i for i in range(3)]
print([f() for f in functions])  # [0, 1, 2]
```

## Advanced Concepts

### 1. Function Objects

Functions are first-class objects:

```python
def greet(name):
    """Say hello"""
    return f"Hello, {name}"

# Functions can be assigned to variables:
say_hello = greet
print(say_hello("Alice"))  # "Hello, Alice"

# Functions can be passed as arguments:
def call_twice(func):
    func()
    func()

def laugh():
    print("Ha!")

call_twice(laugh)  # Prints "Ha!" twice

# Functions can be returned:
def make_adder(n):
    return lambda x: x + n

add_5 = make_adder(5)
print(add_5(3))  # 8

# Functions have attributes:
print(greet.__name__)  # "greet"
print(greet.__doc__)   # "Say hello"
```

### 2. Partial Functions

Pre-fill some arguments:

```python
from functools import partial

def power(base, exponent):
    return base ** exponent

square = partial(power, exponent=2)
print(square(3))  # 9

cube = partial(power, exponent=3)
print(cube(2))  # 8
```

### 3. Function Composition

```python
from functools import reduce

def compose(*functions):
    return reduce(lambda f, g: lambda x: f(g(x)), functions)

def add_one(x):
    return x + 1

def multiply_two(x):
    return x * 2

pipeline = compose(add_one, multiply_two)  # (x*2) + 1
print(pipeline(5))  # 11
```

## Interview Questions

### Q1: Explain the difference between parameters and arguments

Parameters are variables in function definition; arguments are actual values passed in calls.

```python
def func(param1, param2):  # param1, param2 are parameters
    pass

func(arg1, arg2)  # arg1, arg2 are arguments
```

### Q2: What happens with mutable default arguments?

Default arguments are evaluated once at function definition time, not each call.

```python
def func(items=[]):  # [] created once, when function is defined
    items.append(1)
    return items

print(func())  # [1]
print(func())  # [1, 1] ← Same list reused!
```

### Q3: Explain *args and **kwargs

`*args` is a tuple of positional arguments; `**kwargs` is a dict of keyword arguments.

```python
def func(*args, **kwargs):
    print(f"args: {args}")
    print(f"kwargs: {kwargs}")

func(1, 2, 3, name="Alice", age=30)
# args: (1, 2, 3)
# kwargs: {'name': 'Alice', 'age': 30}
```

### Q4: What is a closure? Give an example.

A closure is a function that "captures" variables from its enclosing scope.

```python
def make_multiplier(n):
    def multiply(x):
        return x * n  # Captures n
    return multiply

double = make_multiplier(2)
print(double(5))  # 10
```

### Q5: What's the difference between a decorator and a wrapper?

A decorator is a function that returns a wrapper (modified function).

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("Before")
        result = func(*args, **kwargs)
        print("After")
        return result
    return wrapper

@my_decorator
def greet(name):
    return f"Hello, {name}"
```

### Q6: Explain the late binding problem in closures

Closures capture variables by reference, not by value. The value is looked up when called, not defined.

```python
functions = [lambda: i for i in range(3)]
print([f() for f in functions])  # [2, 2, 2] (all see i=2)

# Fix:
functions = [lambda i=i: i for i in range(3)]
print([f() for f in functions])  # [0, 1, 2]
```

### Q7: When would you use *args vs individual parameters?

Use `*args` when:
- You don't know how many arguments will be passed
- You want to forward arguments to another function

```python
def logger(*args, **kwargs):
    print(f"Calling with {args}, {kwargs}")
    # Pass to another function:
    return actual_function(*args, **kwargs)
```

### Q8: How does a decorator preserve function metadata?

Use `functools.wraps`:

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def greet(name):
    """Greet someone"""
    return f"Hello, {name}"

print(greet.__name__)  # "greet" (not "wrapper")
print(greet.__doc__)   # "Greet someone"
```

## Performance

```python
# Function call overhead is negligible:
%timeit func()  # ~0.05 µs

# Lambda vs function (no performance difference):
%timeit (lambda x: x**2)(5)  # ~0.1 µs
%timeit func_square(5)       # ~0.1 µs

# Closure lookup is fast (array access):
%timeit closure()  # ~0.05 µs

# Global lookup is slower (dict access):
%timeit global_func()  # ~0.1 µs
```
