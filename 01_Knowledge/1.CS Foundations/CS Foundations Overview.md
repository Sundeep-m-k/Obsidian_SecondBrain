# CS Foundations — Overview

## Scope

This subject holds the CS bedrock that everything else (ML&DL, Databases, Systems) quietly assumes you already know: how programs run, how memory works, how computation is bounded, how software is actually engineered.

## Planned sub-areas (fill in as studied)

1. Computational Thinking & Complexity — time/space complexity, Big-O, recursion
2. Programming Language Concepts — types, memory model, concurrency basics
3. Operating Systems Basics — processes, threads, memory management, I/O
4. Networking Basics — HTTP, TCP/IP, DNS, REST
5. Software Engineering Practices — version control, testing, code review, design patterns
6. Computer Architecture Basics — CPU, cache, memory hierarchy

## Why this folder exists

Interview prep (especially anything below the ML layer) and system design both lean on this. Kept separate from DSA because DSA is about *how to solve problems*, this is about *how the machine and the software around it actually works*.
