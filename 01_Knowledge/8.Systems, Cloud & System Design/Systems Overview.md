# Systems, Cloud & System Design — Overview

## Scope

How software runs and scales in the real world: cloud infrastructure, distributed systems, and the system-design vocabulary used in both engineering work and interviews.

## Planned sub-areas (fill in as studied)

1. Cloud Computing Basics — compute/storage/networking primitives, major providers' core services
2. Distributed Systems Concepts — CAP theorem, consistency models, consensus, replication
3. System Design Building Blocks — load balancers, caches, message queues, CDNs
4. Scalability & Reliability — horizontal vs vertical scaling, fault tolerance, SLAs/SLOs
5. System Design Interview Patterns — worked examples (design a URL shortener, design a rate limiter, etc.)

## Why this folder exists

Distinct from [[7.Databases & Data Systems]] (which is about how data itself is modeled and stored) — this is about how whole systems are composed and scaled around that data.
