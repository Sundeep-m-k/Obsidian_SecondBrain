# Binary Classification

## What is it?

**Binary Classification** is a [[Classification]] task where the output belongs to exactly **one of two classes**.

$$y \in \{0, 1\} \quad \text{or equivalently} \quad y \in \{-1, +1\}$$

It is the simplest and most common classification setting. Many multi-class problems are reduced to sequences of binary problems.

---

## Examples

| Problem | Class 0 | Class 1 |
|---|---|---|
| Spam detection | Not spam | Spam |
| Fraud detection | Legitimate | Fraudulent |
| Medical diagnosis | Healthy | Disease present |
| Credit scoring | Default | No default |
| Sentiment analysis | Negative | Positive |

The choice of which class is 0 and which is 1 is arbitrary but affects how you interpret precision and recall.

---

## The Model Output

A binary classifier typically outputs a **probability** $\hat{p} = P(Y = 1 \mid x) \in [0, 1]$, then applies a threshold:

$$\hat{y} = \begin{cases} 1 & \text{if } \hat{p} \geq \tau \\ 0 & \text{if } \hat{p} < \tau \end{cases}$$

Default threshold: $\tau = 0.5$.

**Adjusting $\tau$:**
- Lower $\tau$ → higher Recall, lower Precision (catch more positives, more false alarms)
- Higher $\tau$ → lower Recall, higher Precision (fewer false alarms, miss more positives)
- The right $\tau$ depends on the **cost asymmetry** of FP vs. FN.

---

## Loss Function: Binary Cross-Entropy

Also called **Log Loss**:

$$\mathcal{L} = -\frac{1}{n}\sum_{i=1}^{n}\left[y^{(i)}\log \hat{p}^{(i)} + (1-y^{(i)})\log(1-\hat{p}^{(i)})\right]$$

**Derivation from MLE:** Assume $y \mid x \sim \text{Bernoulli}(\hat{p})$. The likelihood of the training set is:

$$\mathcal{L}(\theta) = \prod_{i=1}^n \hat{p}^{y^{(i)}} (1-\hat{p})^{1-y^{(i)}}$$

Taking the negative log and dividing by $n$ gives Binary Cross-Entropy. **Minimising BCE = Maximum Likelihood Estimation** for a Bernoulli model.

**Behaviour:**
- When $y=1$: loss $= -\log \hat{p}$. If $\hat{p} \approx 1$: low loss. If $\hat{p} \approx 0$: huge loss.
- When $y=0$: loss $= -\log(1-\hat{p})$. If $\hat{p} \approx 0$: low loss. If $\hat{p} \approx 1$: huge loss.

## Confusion Matrix

|  | Predicted $\hat{y}=1$ | Predicted $\hat{y}=0$ |
|---|---|---|
| **Actual $y=1$** | TP (True Positive) | FN (False Negative) |
| **Actual $y=0$** | FP (False Positive) | TN (True Negative) |

**Every binary prediction falls into exactly one of these four cells.**

$$\text{Accuracy} = \frac{TP+TN}{TP+TN+FP+FN}$$

$$\text{Precision} = \frac{TP}{TP+FP}$$

$$\text{Recall (Sensitivity, TPR)} = \frac{TP}{TP+FN}$$

$$\text{Specificity (TNR)} = \frac{TN}{TN+FP}$$

$$\text{False Positive Rate (FPR)} = \frac{FP}{FP+TN} = 1 - \text{Specificity}$$

$$F_1 = \frac{2 \cdot TP}{2 \cdot TP + FP + FN}$$

$$\text{Matthews Correlation Coefficient (MCC)} = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

MCC ranges $[-1, 1]$. It is more informative than accuracy for imbalanced classes.

---

## ROC Curve and AUC

**ROC (Receiver Operating Characteristic) curve:**
- X-axis: FPR $= \frac{FP}{FP+TN}$
- Y-axis: TPR $= \frac{TP}{TP+FN}$ (Recall)
- Generated by sweeping the decision threshold $\tau$ from 0 to 1.

```
TPR
 1 ┤         ╭───────────────
   │        ╱
   │       ╱
   │      ╱        (AUC = area under this curve)
   │     ╱
 0 ┤────╱────────────────────
   0                        1  FPR
          diagonal = random (AUC = 0.5)
```

**AUC interpretation:** Probability that the model ranks a random positive example higher than a random negative example.
$$AUC = P(\hat{p}(x^+) > \hat{p}(x^-))$$

AUC = 1: perfect. AUC = 0.5: random. AUC < 0.5: worse than random (flip the labels).

## Class Imbalance

When one class dominates (e.g., 99% negative), standard accuracy is misleading.

**Example:** 99% negative → accuracy of 99% by always predicting negative. But Recall = 0%.

**Solutions:**

| Method | How |
|---|---|
| **Class weights** | Weight loss: $w_1 = \frac{n}{2n_1}$, $w_0 = \frac{n}{2n_0}$ |
| **Oversampling (SMOTE)** | Synthesise minority class examples |
| **Undersampling** | Remove majority class examples |
| **Threshold tuning** | Lower $\tau$ to increase recall on minority class |
| **PR-AUC** | Use Precision-Recall AUC as metric instead of ROC-AUC |

## Key Algorithms for Binary Classification

- **Logistic Regression** — linear, probabilistic, interpretable. See [[Logistic Regression]].
- **Linear SVM** — large margin, no probabilities. See [[Model]].
- **Decision Tree / Random Forest** — non-linear, handles mixed data.
- **Gradient Boosting** (XGBoost) — state-of-the-art on tabular data.
- **Neural Network** — for complex patterns (images, text).

## One-line Summary

> Binary classification assigns each input to one of two classes by learning a function that estimates the probability of the positive class, with threshold, loss, and evaluation all designed around the two-class structure.
