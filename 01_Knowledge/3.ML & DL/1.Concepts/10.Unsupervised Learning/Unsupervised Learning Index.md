# Unsupervised Learning — Index

> **Position in vault**: `3.ML & DL/1.Concepts/10.Unsupervised Learning/`
> **Purpose**: Finding structure in data without labels — clustering, dimensionality reduction, and density/anomaly-based methods.
> **Prerequisite**: [[Foundations Index]]

## Section Map

| Note | Covers |
|---|---|
| [[Clustering]] | Grouping similar examples without labels |
| [[K Means]] | The standard centroid-based clustering algorithm |

## One-line Summary

> Clustering (K-Means), dimensionality reduction (PCA), and anomaly detection are the three core unsupervised tasks — each finds structure in unlabeled data, just optimizing for a different notion of "structure."
