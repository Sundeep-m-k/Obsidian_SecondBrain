# Hypothesis Testing and P-Values

## What is it?

**Hypothesis testing** uses data to make decisions about population parameters. Ask: "Is this difference real or just noise?"

**P-value:** Probability of observing data this extreme *if the null hypothesis were true*. Smaller p-value = stronger evidence against null.

---

## Null and Alternative Hypotheses

### Null Hypothesis ($H_0$)

Status quo; "no effect," "no difference," "parameter equals specific value."

**Examples:**
- Model A accuracy = Model B accuracy (no difference)
- Drug has no effect (treatment mean = control mean)
- Coin is fair (p = 0.5)

### Alternative Hypothesis ($H_1$)

Research claim; "there is an effect," "there is a difference."

**Examples:**
- Model A accuracy ≠ Model B accuracy (two-sided)
- Drug has effect (treatment mean > control mean) (one-sided)
- Coin is biased (p ≠ 0.5)

### Decision Rule

**Compute p-value.** If p-value < $\alpha$ (typically 0.05), reject $H_0$. Otherwise, fail to reject $H_0$.

**NOT:** "Accept $H_0$" (absence of evidence ≠ evidence of absence)
**SAY:** "Fail to reject $H_0$" (data not strong enough)

---

## P-Value Interpretation

### Definition (Frequentist)

P-value = Probability of observing data *at least this extreme* if $H_0$ is true.

**Example:** Testing if coin is fair (H_0: p=0.5)
```
Flip 10 times, get 8 heads (data: HHHHHHTTHH)
P-value = P(getting ≥8 heads | p=0.5) ≈ 0.055

Interpretation: If coin is fair, ~5.5% chance of seeing ≥8 heads.
Decision: p > 0.05, fail to reject H_0 (not enough evidence)
```

### Common Misinterpretations

**❌ WRONG:** "P-value is probability H_0 is true"
- P-value is P(data | H_0), not P(H_0 | data)
- If H_0 is true by assumption, its probability is not the question

**❌ WRONG:** "P-value < 0.05 means 95% chance H_1 is true"
- Close, but imprecise; doesn't account for prior probability of H_1

**✓ CORRECT:** "P-value is probability of observing data this extreme if H_0 were true"
- If p < 0.05, reject H_0; data unlikely under null

---

## Types of Errors

|  | $H_0$ True | $H_0$ False |
|---|---|---|
| **Reject $H_0$** | Type I Error (False Positive) | ✓ Correct |
| **Fail to Reject $H_0$** | ✓ Correct | Type II Error (False Negative) |

### Type I Error (α)

False positive. Reject $H_0$ when it's actually true.

**Example:** Conclude drug works when it doesn't.

**Probability:** $\alpha$ (significance level; typically 0.05)

### Type II Error (β)

False negative. Fail to reject $H_0$ when it's actually false.

**Example:** Conclude drug doesn't work when it does.

**Probability:** $\beta$ (typically 0.1-0.2; chosen by study design)

### Power

Power = $1 - \beta$ = Probability of correctly rejecting $H_0$ when false.

**Example:** Power = 0.8 means 80% chance of detecting real effect.

**Trade-off:** Smaller $\alpha$ (fewer false positives) increases $\beta$ (more false negatives).

## Common Statistical Tests

### 1. T-Test (Comparing Means)

**Null:** $\mu_1 = \mu_2$ (means are equal)

**Test statistic:**
$$t = \frac{\bar{x}_1 - \bar{x}_2}{SE}$$

**Python:**
```python
from scipy import stats

# Independent t-test
x1 = [85, 87, 88, 86, 84]  # Model A accuracy repeated trials
x2 = [82, 84, 83, 85, 81]  # Model B accuracy

t_stat, p_value = stats.ttest_ind(x1, x2)
print(f"t={t_stat:.3f}, p={p_value:.3f}")

if p_value < 0.05:
    print("Reject H_0: Models significantly different")
else:
    print("Fail to reject H_0: No significant difference")
```

**Assumptions:** Data approximately normal, similar variances

**When to use:** Comparing two groups' means

### 2. Chi-Square Test (Categorical)

**Null:** Variables are independent

**Test statistic:** $\chi^2 = \sum \frac{(O - E)^2}{E}$ (observed vs. expected frequencies)

**Python:**
```python
from scipy.stats import chi2_contingency

# Contingency table
table = [[45, 5], [8, 42]]  # Results: Model A right/wrong, Model B right/wrong
chi2, p_value, dof, expected = chi2_contingency(table)

if p_value < 0.05:
    print("Models have significantly different error rates")
else:
    print("No significant difference")
```

### 3. Mann-Whitney U Test (Non-parametric)

Non-parametric alternative to t-test. No normality assumption.

**Python:**
```python
from scipy.stats import mannwhitneyu

u_stat, p_value = mannwhitneyu(x1, x2, alternative='two-sided')
```

**When to use:** Non-normal data, small sample, ranked data

## P-Hacking and Multiple Testing Problem

### P-Hacking

Trying many analyses until one gives p < 0.05. False positive rate inflates.

**Example:**
```
Try 100 independent statistical tests, each with α=0.05
Expected false positives: 100 × 0.05 = 5 tests
Researcher picks the one with lowest p-value, reports it as "significant"
← That p-value is misleading; due to multiple testing
```

**Solution:** Correct for multiple testing (see [[17.3_Multiple_Testing_Correction]]).

### Pre-Registration

Specify hypothesis and statistical test *before* data collection. Prevents p-hacking.

## Interview Questions

**Q: What is a p-value and how do you interpret it?**

P-value = Probability of observing data *at least this extreme* if the null hypothesis were true. Example: Two models' t-test gives p=0.03. Means: If models truly perform equally, ~3% chance of seeing this difference. Interpretation: p < 0.05 → reject null, conclude models differ significantly. NOT "95% chance H_0 is false" (wrong interpretation). Correct: "Data unlikely under H_0; reject it." See [[17.1_Confidence_Intervals_and_Bootstrap]].

---

**Q: What's the difference between Type I and Type II error?**

**Type I (α):** False positive; reject H_0 when it's true. Example: Conclude drug works when it doesn't. Probability α (typically 0.05). **Type II (β):** False negative; fail to reject H_0 when it's false. Example: Conclude drug doesn't work when it does. Probability β (typically 0.1-0.2). Trade-off: Lower α (fewer false alarms) increases β (miss more effects). Power = 1 - β = ability to detect real effects. See [[17.3_Multiple_Testing_Correction]].

---

**Q: You run a t-test comparing two models' accuracy. P-value is 0.08. Should you conclude they're different?**

No. p > 0.05, so fail to reject null hypothesis. Models' accuracies are not significantly different (at α=0.05 level). Don't say "no difference exists"; say "no significant difference" (data not strong enough to conclude). Could be: (1) True no difference. (2) Real difference but sample too small to detect (Type II error). Increase sample size and retest if suspect #2. See [[17.1_Confidence_Intervals_and_Bootstrap]].

---

**Q: What is power and how do you increase it?**

Power = 1 - β = Probability of correctly rejecting H_0 when it's false. Example: Power=0.8 means 80% chance of detecting real effect. To increase power: (1) Increase sample size (largest impact). (2) Increase effect size (harder to control; depends on phenomenon). (3) Decrease variance (better measurement, reduce noise). (4) Lower α (makes Type I/II tradeoff). In practice: Design studies with power ≥ 0.8 (standard). See [[17.1_Confidence_Intervals_and_Bootstrap]].

---

**Q: Two models have different accuracies on the test set. Should you always run a significance test?**

Not always. Significance tests answer: "Is this difference real or random noise?" If: (1) Large sample size (1000+ examples), even tiny differences are "significant." (2) Small sample size, large differences might not be "significant." Also consider: Practical significance (does 0.5% improvement matter?). For model comparison, report both p-value and confidence interval. Example: "Model B is 2% more accurate (95% CI: [0.5%, 3.5%], p=0.02)." See [[17.1_Confidence_Intervals_and_Bootstrap]].
