# Preprocessing Pipelines

## What is it?

A **preprocessing pipeline** chains multiple preprocessing steps (scaling, encoding, imputation) into a single object. Automatically prevents data leakage: fit on train, apply to test.

**Benefits:**
- Prevents leakage (fit only on train)
- Reproducible (same preprocessing every time)
- Portable (serialize and deploy)
- Clean code

---

## sklearn Pipeline

### Basic Structure

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression

pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('model', LogisticRegression())
])

# Fit (scaler on X_train)
pipeline.fit(X_train, y_train)

# Predict (scaler applies train's mean/std to X_test)
predictions = pipeline.predict(X_test)
```

**Automatically:**
1. Fit StandardScaler on X_train (learn mean/std)
2. Transform X_train using those statistics
3. Fit LogisticRegression on transformed X_train
4. When predicting: Transform X_test using train's statistics, predict

### Multiple Steps

```python
pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='mean')),
    ('scaler', StandardScaler()),
    ('selector', SelectKBest(k=10)),
    ('model', RandomForestClassifier())
])

pipeline.fit(X_train, y_train)
predictions = pipeline.predict(X_test)
```

**Order matters:** Each transformer's output is next transformer's input.

### Handling Mixed Data Types

```python
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.compose import ColumnTransformer

# Different processing for different columns
preprocessor = ColumnTransformer([
    ('num', StandardScaler(), numeric_features),
    ('cat', OneHotEncoder(handle_unknown='ignore'), categorical_features)
])

pipeline = Pipeline([
    ('preprocessor', preprocessor),
    ('model', LogisticRegression())
])

pipeline.fit(X_train, y_train)
predictions = pipeline.predict(X_test)
```

**Benefits:**
- Encode categoricals, scale numericals, simultaneously
- Same pipeline fits on train, applies to test
- Clean separation of concerns

## Cross-Validation with Pipelines

Pipelines + nested CV (hyperparameter tuning):

```python
from sklearn.model_selection import GridSearchCV, cross_val_score

pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('model', LogisticRegression())
])

# Hyperparameter grid (note naming: 'step__param')
param_grid = {
    'model__C': [0.1, 1.0, 10.0],
    'model__penalty': ['l2']
}

# Grid search with CV
grid_search = GridSearchCV(pipeline, param_grid, cv=5)
grid_search.fit(X_train, y_train)

# Best model
best_pipeline = grid_search.best_estimator_
best_score = grid_search.best_score_

# Evaluate on test
test_predictions = best_pipeline.predict(X_test)
```

**Automatically:**
- For each CV fold: Fit pipeline on train fold, evaluate on val fold
- Scaler fit inside fold (prevents leakage)
- Hyperparameters tuned on val
- Final best pipeline evaluated on test

## Serialization and Deployment

### Saving Pipeline

```python
import pickle

# Save entire pipeline (scaler + model)
with open('model_pipeline.pkl', 'wb') as f:
    pickle.dump(pipeline, f)
```

### Loading and Using

```python
# Load
with open('model_pipeline.pkl', 'rb') as f:
    pipeline = pickle.load(f)

# Predict on new data
new_data = pd.DataFrame({...})
predictions = pipeline.predict(new_data)
# Scaler automatically applies training statistics!
```

**Critical:** Save the entire pipeline, not just model. Scaler must have training statistics.

### JSON for Transparency

```python
import json

# Save scaler parameters
scaler_params = {
    'mean': pipeline['scaler'].mean_.tolist(),
    'std': pipeline['scaler'].scale_.tolist()
}

with open('scaler_params.json', 'w') as f:
    json.dump(scaler_params, f)

# Later, reconstruct
scaler = StandardScaler()
scaler.mean_ = np.array(json.load(open('scaler_params.json'))['mean'])
```

**Use case:** Production systems that can't import sklearn (e.g., mobile, embedded systems).

## Real-World Example

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.model_selection import train_test_split, GridSearchCV, cross_val_score
from sklearn.linear_model import LogisticRegression

# Data
X = pd.DataFrame({
    'age': [25, 30, np.nan, 40],
    'income': [50000, 60000, 70000, np.nan],
    'city': ['NYC', 'LA', 'NYC', 'Chicago']
})
y = [0, 1, 1, 0]

# Define features
numeric_features = ['age', 'income']
categorical_features = ['city']

# Pipeline
numeric_transformer = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])

categorical_transformer = OneHotEncoder(handle_unknown='ignore')

preprocessor = ColumnTransformer([
    ('num', numeric_transformer, numeric_features),
    ('cat', categorical_transformer, categorical_features)
])

pipeline = Pipeline([
    ('preprocessor', preprocessor),
    ('model', LogisticRegression())
])

# Split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25)

# Hyperparameter tuning
param_grid = {'model__C': [0.1, 1.0, 10.0]}
grid_search = GridSearchCV(pipeline, param_grid, cv=3)
grid_search.fit(X_train, y_train)

# Evaluate
test_score = grid_search.best_estimator_.score(X_test, y_test)
print(f"Test accuracy: {test_score}")

# Save
import pickle
with open('pipeline.pkl', 'wb') as f:
    pickle.dump(grid_search.best_estimator_, f)

# Load and use
with open('pipeline.pkl', 'rb') as f:
    loaded_pipeline = pickle.load(f)
new_predictions = loaded_pipeline.predict(X_test)
```

## Common Pitfalls

| Pitfall | Problem | Fix |
|---------|---------|-----|
| Save model but not scaler | Inference fails; can't apply statistics | Save entire pipeline |
| Fit pipeline on all data | Leakage | Always split first |
| Forget pipeline order | Preprocessing applied in wrong order | Check step names and order |
| Hyperparameter naming ('model__C') | GridSearchCV doesn't find params | Use correct 'step__param' format |

## Interview Questions

**Q: What is a preprocessing pipeline and why is it useful?**

A pipeline chains preprocessing steps (imputation, scaling, encoding) + model into one object. Useful because: (1) Prevents leakage (fit only on train, applies to test automatically). (2) Reproducible (same pipeline every time). (3) Portable (serialize and deploy). (4) Clean code (one fit/predict call instead of manual steps). sklearn Pipeline handles fitting on train correctly; no manual mean/std tracking. See [[15.5_Train_Val_Test_Framework]].

---

**Q: How does sklearn Pipeline prevent data leakage?**

Pipeline fits each transformer on training data only. Example: StandardScaler().fit() on X_train learns mean/std from train. When pipeline.predict(X_test), scaler uses train's mean/std, not test's. Manual code: Must manually fit on train, apply to test (easy to forget). Pipeline automates this; fit() on train, predict() on test does it right automatically. See [[16.6_Data_Leakage_Prevention]].

---

**Q: You have numeric and categorical features. How do you handle both in a pipeline?**

Use ColumnTransformer to apply different preprocessing to different columns:
```python
preprocessor = ColumnTransformer([
    ('num', StandardScaler(), numeric_features),
    ('cat', OneHotEncoder(), categorical_features)
])
```

Then put in pipeline:
```python
pipeline = Pipeline([
    ('preprocessor', preprocessor),
    ('model', LogisticRegression())
])
```

ColumnTransformer handles both simultaneously; pipeline ensures fitting only on train. See [[16.2_Categorical_Encoding]], [[16.4_Feature_Scaling_and_Normalization]].

---

**Q: If you save a trained pipeline, what do you need to save?**

Save the entire pipeline object, not just the model. Example: `pickle.dump(pipeline, file)` saves scaler + model with training statistics baked in. Don't save model separately; when loaded, scaler has train's mean/std. If you saved just model, you'd need to manually track and apply scaler statistics, error-prone. Use pickle for Python; JSON for cross-language (but more work). See [[16.4_Feature_Scaling_and_Normalization]].
